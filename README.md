# AI WhatsApp Chatbot for Grocery Store
By M Shahid Fareed - Lahore, Pakistan

This Python bot auto-replies to customer price queries on WhatsApp.
It connects with Google Sheets for auto price updates.

Features:
- 24/7 Auto Reply
- Google Sheets Integration
- Works for Grocery & Clothing Stores
